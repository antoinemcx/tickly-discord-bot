# Términos de Servicio

**Última actualización: 28 de septiembre de 2026**

Al usar Tickly ("el bot", "nosotros"), aceptas estos Términos de Servicio.
Si no estás de acuerdo, no uses el bot.

## 1. Elegibilidad

Debes cumplir con los [Términos de Servicio de Discord](https://discord.com/terms) y tener al menos
13 años (o la edad mínima requerida por las leyes de tu país) para usar Tickly. También debes
tener una cuenta válida de Todoist para usar la mayoría de las funciones.

## 2. Uso del Bot

Tickly te permite crear y gestionar tareas de Todoist desde Discord. Aceptas usar el bot
solo para su propósito previsto y no:
- Intentar abusar, explotar o interrumpir el bot o los servicios a los que se conecta
- Usar el bot para cualquier propósito ilegal o no autorizado
- Violar los términos de servicio de Discord o Todoist

## 3. Servicios de Terceros

Tickly depende de servicios de terceros para funcionar:
- **Todoist** — los datos de tareas que envías se transmiten a Todoist. Eres responsable de cumplir
  con los [Términos de Servicio de Todoist](https://todoist.com/tos).
- **Discord** — el bot opera en la plataforma de Discord. Eres responsable de cumplir
  con los [Términos de Servicio de Discord](https://discord.com/terms).

## 4. Cuenta y Sesión

Al ejecutar `/todoist login`, autorizas a Tickly a interactuar con Todoist en tu nombre.
Puedes revocar esto en cualquier momento con `/todoist logout`, que elimina tu sesión almacenada y
token de acceso. Eres responsable de mantener tu cuenta de Todoist segura.

tiempo de actividad. El bot puede ser modificado, interrumpido o discontinuado en cualquier momento sin previo aviso.
